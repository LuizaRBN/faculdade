## ▶️ Como executar os exercícios

1. Baixe o repositório para o seu computador:

```bash
git clone https://github.com/LuizaRBN/faculdade.git
```

2. Abra a pasta do exercício que quiser.
3. Dê dois cliques no arquivo que termina com `.sln` (ele abre o projeto no Visual Studio).
4. Aperte a tecla **F5** (ou clique no botão verde ▶ no topo) para rodar o programa.
